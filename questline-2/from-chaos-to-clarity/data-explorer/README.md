# Data Explorer Overview

This dataset contains a small sales sample with columns for order information, customer age, region, sales amount, discount percentage, return status, and days since the last purchase.

## Observations
- The dataset has 12 rows and 7 columns.
- Customer age, discount percentage, and days since last purchase contain missing values.
- The numerical fields include `customer_age`, `sales_amount`, `discount_pct`, and `days_since_last_purchase`.
- The summary statistics show variation in order value and customer demographics, which is helpful for quick quality checks before deeper analysis.

## Python workflow used
- Loaded the CSV file with Pandas.
- Printed the shape of the dataset.
- Listed all columns.
- Checked the data types for each column.
- Identified missing values.
- Generated summary statistics for numerical features.
